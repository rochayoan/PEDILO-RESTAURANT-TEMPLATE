# Alta de un restaurante
1. Crear un repositorio nuevo desde la plantilla y hacerlo privado para la operación del cliente.
2. Configurar una instancia propia y aislada de Backend Central, PostgreSQL, Kapso, OpenAI y Telegram.
3. Copiar .env.example a .env y sustituir los valores de muestra.
4. Agregar logo y fotos propias, categorías y precios reales en Central.
5. Ejecutar npm install y npm run validate, npm test y npm run build.
6. Desplegar por separado agente y menú con HTTPS y dominios propios.
7. Validar firma y eventos Kapso, rutas privadas, catálogo, pedidos, errores, pagos, reintentos y experiencia móvil.
8. Solo habilitar RESTAURANT_ORDERING_ENABLED tras aprobar el flujo completo en pruebas.

No importar historiales de mensajes, bases de datos, fotografías, tokens, enlaces privados ni recursos comerciales de otro restaurante.
